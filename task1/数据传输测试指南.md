# VPN 数据传输测试指南

## 🎯 测试目标
验证Windows客户端是否能将数据包成功发送到Linux虚拟机上的服务端，**不进行网络转发**。

## 📁 测试文件
- `task1/server/server_test.cpp` - 简化测试服务端（只接收和分析数据）
- `task1/client/client_test.cpp` - 测试客户端（发送数据并接收确认）

## 🖥️ 服务端测试步骤（Linux虚拟机）

### 1. 编译测试服务端
```bash
cd /workspace/task1/server
g++ server_test.cpp -o server_test -lboost_system -lboost_thread -lpthread -lssl -lcrypto
```

### 2. 运行测试服务端
```bash
./server_test 443
```

**预期输出**：
```
=== VPN数据传输测试服务端 ===
监听端口: 443
功能: 仅接收并分析客户端数据，不进行转发
===============================

✅ SSL证书加载成功
🚀 测试服务器已启动，等待客户端连接...
```

## 💻 客户端测试步骤（Windows）

### 1. 准备文件
确保客户端目录有以下文件：
- `client_test.cpp`
- `wintun.h` 和 `wintun.dll`
- `certs/server.crt` (证书文件)

### 2. 编译测试客户端
```cmd
g++ client_test.cpp -o client_test.exe -lws2_32 -liphlpapi -lole32 -lssl -lcrypto -lboost_thread-mt
```

### 3. 运行测试客户端（需管理员权限）
```cmd
client_test.exe <虚拟机IP> 443
```

例如：
```cmd
client_test.exe 192.168.1.100 443
```

## 📊 测试验证方法

### 1. 连接验证
当客户端连接成功时，服务端会显示：
```
🔗 新客户端连接，开始SSL握手...
✅ SSL握手成功，客户端已连接
```

### 2. 数据传输验证
在Windows客户端上执行以下命令触发网络数据包：
```cmd
ping 8.8.8.8
```

**客户端预期输出**：
```
📤 发送数据包 #1
   大小: 84 字节
   前16字节: 45 00 00 54 00 01 00 00 40 01 ...
   ✅ SSL发送成功: 84 字节
✅ 收到服务端确认 #1: ACK_1
```

**服务端预期输出**：
```
📦 接收到数据包 #1
   大小: 84 字节
   内容: 45 00 00 54 00 01 00 00 40 01 ...
   🌐 IP包分析:
      版本: IPv4
      头部长度: 20 字节
      总长度: 84 字节
      协议: ICMP
      源IP: 10.8.0.2
      目标IP: 8.8.8.8
   ✅ 已发送确认: ACK_1
```

## ✅ 成功标准

### 数据传输测试通过的标准：
1. ✅ **SSL连接建立** - 客户端和服务端都显示SSL握手成功
2. ✅ **数据包发送** - 客户端显示"SSL发送成功"
3. ✅ **数据包接收** - 服务端显示"接收到数据包"并分析内容
4. ✅ **确认回复** - 客户端收到服务端的ACK确认消息

### 如果测试失败，检查：
- ❌ SSL握手失败 → 检查证书文件和防火墙
- ❌ 连接失败 → 检查网络连通性和端口
- ❌ 无数据包 → 检查WinTun驱动和TUN设备配置
- ❌ 数据发送失败 → 检查SSL连接状态

## 🔧 故障排除

### 1. 证书问题
如果SSL证书加载失败：
```bash
cd /workspace/task1/server
./generate_certs.sh
```

### 2. 防火墙问题
Linux服务端：
```bash
sudo ufw allow 443
# 或
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT
```

### 3. WinTun问题
Windows客户端需要：
- 管理员权限运行
- WinTun驱动正确安装
- `wintun.dll`在程序同一目录
